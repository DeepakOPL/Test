Monolithic Pattern

Limitations:
	- Tight Coupling of Services
		a. If one service is down other services also get affected
		b. If one service is planned to redploy other also get affected
	- Problem of Scalability
	- Fixed TechStack

Microservices:
	
	- Microservices are a software architecture approach where an application is divided into small , independent and selft contained services that communicate with each other through APIs.
	- This allows for faster development, deployment and scalability.

Property	   		Example/Syntax							Description
id			   	   - id : user-contact-service				Unique identifier for the route
uri					 uri: lb://service-contact-user			Target microservice URL
predicates	 	predicates :
					- Path=/gateway/user/**					Conditions to match the incoming request (like URL path)
filters		   	filters :									Pre-processing or Post-processing (Ex: StripPrefix, AddHeader)
StripPrefix			- StripPrefix=1							Removes N segments from the path (1 means /gateway will be removed)

-----------------------------------------------------------------

Filter					Description

StripPrefix=1			Removes prefix from path
AddRequestHeader		Adds custom request header
RewritePath				Rewrites the request path
